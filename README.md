## 拾星小宠

## 介绍
一款以家庭为主的宠物养成系统，可以帮助家长更好的与孩子进行沟通交流。家长与孩子之间可以进行多种互动。主要以完成各项任务来对宠物进行喂养，使宠物进行升级。这款软件可以有效提高家庭氛围，以及家长与孩子之间的互动。不仅可以使家长能监督孩子，也可以是孩子监督家长，使家庭更加和谐。父母与孩子之间形成一种相互进步的状态。


## 功能
### 0. Onboard 界面
3 - 5 个界面介绍我们的应用程序 features （仅在第一次打开）

### 1.注册登录
用手机号注册登录
新用户登录进去之后在主界面显示多种宠物的各种形态。

### 2.家庭组
2.1
登录人员为管理员，管理员可以添加或者删除家庭成员（包括大人小孩）来形成一个家庭组。
2.2
管理员可以对各项任务进行设置，包括任务的内容和分数。
2.3
管理员可以直接对家庭成员进行增减，包含相关人员宠物的增加和删除。
2.3
管理员添加家庭组成员之后，自动添加相关成员的宠物。
2.4
家庭成员需要上传可选的头像，如果没有上传则采用默认头像。

### 3.主界面
主界面显示家庭组成员的宠物喂养进度及下方的各种功能按钮，包括：宠物喂养，宠物商店，抽奖界面，家庭组管理，个人信息。

### 4.宠物养成系统
管理员可以设置任务，包括任务所获得的积分数量。通过各项任务加减分对宠物进行喂养，得到的分数直接喂给宠物。

### 5.宠物商店


### 5.抽奖界面
奖品设置可以为额外的积分或者各种现实奖励。获得的积分奖励直接喂养给宠物。

### 6.个人账号信息
包含个人信息及各项设置
